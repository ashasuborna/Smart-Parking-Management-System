# Smart Parking Management System

## Quick Start

### Build
```bash
make clean
make
```

### Run
```bash
./smart_parking.exe
```

## Features
- Car Entry/Exit
- File Handling (CSV)
- MySQL Integration (optional)
- Data Backup System

## MySQL Setup (Optional)
```bash
make ENABLE_MYSQL=1
```
