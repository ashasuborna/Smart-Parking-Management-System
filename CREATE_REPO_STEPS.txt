========================================
HOW TO CREATE GITHUB REPOSITORY
========================================

STEP 1: Create Repository on GitHub
------------------------------------
1. Open web browser
2. Go to: https://github.com/new
3. Sign in if needed

STEP 2: Fill Repository Details
--------------------------------
- Repository name: Smart-Parking-Management-System
- Description: Smart Parking Management System - University Project in C with GTK+3
- Choose: Public (or Private if you prefer)
- IMPORTANT: DO NOT check "Initialize with README"
- DO NOT add .gitignore (we already have one)
- DO NOT choose a license (optional)

STEP 3: Create Repository
--------------------------
Click the green "Create repository" button

STEP 4: Push Your Code
-----------------------
After creating, come back to terminal and run:

git push -u origin master

If it says "main" branch instead, run:
git branch -M main
git push -u origin main

STEP 5: Authentication
-----------------------
If asked for credentials:
- Username: ashasuborna
- Password: Use Personal Access Token (NOT your password)
  - Get token: https://github.com/settings/tokens
  - Click "Generate new token (classic)"
  - Select "repo" scope
  - Copy the token and use it as password

YOUR REPOSITORY WILL BE AT:
