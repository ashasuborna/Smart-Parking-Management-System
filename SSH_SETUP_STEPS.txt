========================================
SSH SETUP FOR GITHUB
========================================

STEP 1: Generate SSH Key
-------------------------
Open PowerShell or Git Bash and run:

ssh-keygen -t ed25519 -C "your_email@example.com"

(Press Enter 3 times to use defaults)

STEP 2: Copy Your Public Key
-----------------------------
Run this command:

cat ~/.ssh/id_ed25519.pub

OR on Windows PowerShell:
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub

Copy the entire output (starts with ssh-ed25519...)

STEP 3: Add Key to GitHub
--------------------------
1. Go to: https://github.com/settings/keys
2. Click "New SSH key"
3. Title: "My Computer" (or any name)
4. Paste your public key
5. Click "Add SSH key"

STEP 4: Change Remote to SSH
-----------------------------
In your project directory, run:

git remote set-url origin git@github.com:ashasuborna/Smart-Parking-Management-System.git

STEP 5: Test Connection
------------------------
ssh -T git@github.com

(Should say: "Hi ashasuborna! You've successfully authenticated...")

STEP 6: Push
------------
git push -u origin master

========================================
That's it! SSH is more secure and easier.
