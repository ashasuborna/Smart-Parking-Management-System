========================================
SIMPLE STEP-BY-STEP GUIDE
========================================

You have already:
✅ Installed MSYS2
✅ Installed the required packages (gcc, gtk3, etc.)

NOW DO THIS:

STEP 1: Open MSYS2 Terminal
---------------------------
1. Press the Windows key on your keyboard
2. Type: MSYS2 MinGW 64-bit
3. Click on "MSYS2 MinGW 64-bit" (the one with MinGW in the name)
4. A black terminal window will open

STEP 2: Go to Your Project
---------------------------
In the terminal window, type this EXACTLY (copy and paste):

cd "/c/Users/Suborna Asha/OneDrive/Desktop/Smart Parking Management System"

Press Enter

STEP 3: Build the Project
-------------------------
In the same terminal, type:

make

Press Enter

Wait for it to finish (you'll see lots of text scrolling)

STEP 4: Run the Application
----------------------------
In the same terminal, type:

./smart_parking.exe

Press Enter

The application window should open!

STEP 5: Login
-------------
When the login window appears:
- Username: admin
- Password: admin123
- Click "Login"

DONE! You can now use the application.

========================================
TROUBLESHOOTING
========================================

If "make" says "command not found":
- Make sure you're in "MSYS2 MinGW 64-bit" (not regular MSYS2)

If you get errors about GTK+:
- Make sure you installed: pacman -S mingw-w64-x86_64-gtk3

If the window doesn't open:
- Make sure you're running from MSYS2 terminal, not PowerShell
